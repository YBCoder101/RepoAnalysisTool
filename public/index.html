Metric definitions
  • l+ — lines added  ·  l− — lines removed  ·  δ growth = l+ − l−
  • λ churn = l+ + l−  ·  n modifications — commits in H that changed the object (churn > 0)
  • η modification frequency = n / |H|  ·  ρ churn rate = λ / |H|
  • author modifications na — commits by author a changing the object  ·  author churn Aa — lines changed by a
  • ownership ωa = Aa / λ  ·  only non-merge commits reachable from HEAD are counted; renames are followed (≥50% similarity); binary files are not measured; deletions count as removals.
